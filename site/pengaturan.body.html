Hubungkan ke GitHub

Dilakukan satu kali. Token membuat halaman ini boleh menulis ke repo Anda.

  1. Buka pembuat token GitHub. Pilih Only select repositories lalu repo crypto-sastra; masa berlaku 90 hari.
  2. Repository permissions: Secrets, Actions, Contents, masing-masing Read and write. Generate lalu salin token.
  3. Tempel di bawah, tekan Tes koneksi.

Token hanya dikirim ke api.github.com dan hidup di memori halaman ini. Opsi "ingat" menyimpannya di browser; domain github.io dipakai bersama semua situs Anda, jadi aktifkan hanya di perangkat pribadi.
